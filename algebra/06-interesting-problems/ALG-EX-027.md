## 题目

四元数形如 $q = a + bi + cj + dk$，其中 $a, b, c, d \in \mathbb{R}$，乘法满足 $i^2 = j^2 = k^2 = ijk = -1$，由此得到 $ij = k$、$jk = i$、$ki = j$ 以及 $ji = -k$、$kj = -i$、$ik = -j$。定义范数 $N(q) = a^2 + b^2 + c^2 + d^2$。完成以下各题：

1. 写出四元数乘法的分量公式，并证明 $N(q_1 q_2) = N(q_1) N(q_2)$。
2. 对固定 $q$，定义左乘矩阵 $L_q$（$4 \times 4$ 实矩阵），证明 $L_q^{\mathsf{T}} L_q = N(q) I_4$，从而 $\det L_q = N(q)^2$；再由 $\det(L_{q_1} L_{q_2}) = \det L_{q_1} \det L_{q_2}$ 推出欧拉四平方和恒等式，并写出展开形式。
3. 取 $q_1 = 1 + 2i$、$q_2 = 3 + 4j$ 具体验证。
4. 讨论：为什么这类**双线性**平方和恒等式只对 $n = 1, 2, 4, 8$ 存在（Hurwitz 定理，点到为止）。

## 分析

四元数乘法对每个变量都是线性的。固定 $q_1$ 后，"左乘 $q_1$"是 $\mathbb{R}^4$ 上的线性变换，可以用 $4 \times 4$ 实矩阵 $L_{q_1}$ 表示。这一步把代数问题转成了矩阵问题：范数的乘法性质就对应行列式的乘法性质。

关键的第二点是 $L_q^{\mathsf{T}} L_q = N(q) I_4$。它说明左乘 $q$ 是一个"缩放的正交变换"：$L_q$ 的四个列向量两两正交且长度都是 $\sqrt{N(q)}$。这个恒等式可以从乘法表直接算出，于是 $\det L_q$ 的绝对值被确定；符号再由连通性确定——单位四元数构成的三维球面是连通的，而 $\det L_q / N(q)^2$ 只能取 $\pm 1$ 且连续。有了 $\det L_q = N(q)^2$，四平方和恒等式就是行列式乘法定理的展开。

## 证明 / 解答

### 第一步：乘法公式与范数

把两个四元数按分配律展开，并用乘法表把 $i$、$j$、$k$ 的乘积化成标准形式。注意 $ij = k$ 而 $ji = -k$，乘积的次序不能交换。整理后得到

$$
\begin{aligned}
q_1 q_2 ={}& (a_1 a_2 - b_1 b_2 - c_1 c_2 - d_1 d_2) + (a_1 b_2 + b_1 a_2 + c_1 d_2 - d_1 c_2)\, i \\
& + (a_1 c_2 - b_1 d_2 + c_1 a_2 + d_1 b_2)\, j + (a_1 d_2 + b_1 c_2 - c_1 b_2 + d_1 a_2)\, k.
\end{aligned}
$$

乘法满足结合律，可以按乘法表逐项验证。记共轭 $\bar q = a - bi - cj - dk$，直接相乘时交叉项两两相消，得 $q\bar q = \bar q q = N(q)$。特别地，当 $N(q) \ne 0$ 时 $q^{-1} = \bar q / N(q)$，所以每个非零四元数都可逆；四元数因此构成一个可除代数（类似域，但乘法不交换）。

### 第二步：左乘矩阵

固定 $q = a + bi + cj + dk$，定义 $L_q : \mathbb{R}^4 \to \mathbb{R}^4$ 为 $L_q(p) = qp$，其中 $p = p_0 + p_1 i + p_2 j + p_3 k$。取基 $1, i, j, k$，四个基向量的像为

$$
q \cdot 1 = a + bi + cj + dk, \qquad q \cdot i = -b + ai + dj - ck,
$$

$$
q \cdot j = -c - di + aj + bk, \qquad q \cdot k = -d + ci - bj + ak.
$$

把像的坐标按列排成矩阵，得到

$$
L_q = \begin{pmatrix}
a & -b & -c & -d \\
b & a & -d & c \\
c & d & a & -b \\
d & -c & b & a
\end{pmatrix}.
$$

由乘法的结合律，$L_{q_1 q_2}(p) = (q_1 q_2)p = q_1(q_2 p) = L_{q_1}(L_{q_2}(p))$，即 $L_{q_1 q_2} = L_{q_1} L_{q_2}$。

### 第三步：正交性与行列式

由第二步的矩阵读出四个列向量 $v_1 = (a,b,c,d)$、$v_2 = (-b,a,d,-c)$、$v_3 = (-c,-d,a,b)$、$v_4 = (-d,c,-b,a)$。逐对计算内积：

$$
\begin{aligned}
v_1 \cdot v_2 &= -ab + ab + cd - cd = 0, & v_1 \cdot v_3 &= -ac - bd + ac + bd = 0, \\
v_1 \cdot v_4 &= -ad + bc - bc + ad = 0, & v_2 \cdot v_3 &= bc - ad + ad - bc = 0, \\
v_2 \cdot v_4 &= bd + ac - bd - ac = 0, & v_3 \cdot v_4 &= cd - cd - ab + ab = 0,
\end{aligned}
$$

并且每个列向量的长度平方都是 $N(q)$，例如 $v_2 \cdot v_2 = b^2 + a^2 + d^2 + c^2 = N(q)$。因此 $L_q^{\mathsf{T}} L_q = N(q) I_4$。取行列式得 $\det(L_q)^2 = \det(N(q) I_4) = N(q)^4$。当 $N(q) \ne 0$ 时令 $\varepsilon(q) = \det L_q / N(q)^2$，则 $\varepsilon(q) \in \{1, -1\}$；$\varepsilon$ 在 $N(q) = 1$ 的单位球面 $S^3$ 上连续，而 $S^3$ 连通，故 $\varepsilon$ 恒等于 $\varepsilon(1) = 1$。对一般的 $q \ne 0$，令 $u = q/\sqrt{N(q)}$，则 $N(u) = 1$ 且 $L_q = \sqrt{N(q)}\,L_u$，故 $\det L_q = N(q)^2$；$q = 0$ 时两边都为零矩阵与零。

### 第四步：欧拉四平方和恒等式

由 $L_{q_1 q_2} = L_{q_1} L_{q_2}$、行列式乘法定理（[[ALG-THM-015]]）与第三步的结论，

$$
N(q_1 q_2)^2 = \det L_{q_1 q_2} = \det(L_{q_1} L_{q_2}) = \det L_{q_1} \det L_{q_2} = N(q_1)^2 N(q_2)^2.
$$

范数非负，两边开方得 $N(q_1 q_2) = N(q_1) N(q_2)$。把第一步的乘法公式代入，就得到欧拉四平方和恒等式

$$
\begin{aligned}
& (a_1^2 + b_1^2 + c_1^2 + d_1^2)(a_2^2 + b_2^2 + c_2^2 + d_2^2) \\
& \quad = (a_1 a_2 - b_1 b_2 - c_1 c_2 - d_1 d_2)^2 + (a_1 b_2 + b_1 a_2 + c_1 d_2 - d_1 c_2)^2 \\
& \quad \quad + (a_1 c_2 - b_1 d_2 + c_1 a_2 + d_1 b_2)^2 + (a_1 d_2 + b_1 c_2 - c_1 b_2 + d_1 a_2)^2.
\end{aligned}
$$

它说明两个各有四个平方的数相乘，其积仍可写成四个平方之和，并且给出了显式的双线性公式。

### 第五步：具体验证

取 $q_1 = 1 + 2i$、$q_2 = 3 + 4j$，则 $q_1 q_2 = (1 + 2i)(3 + 4j) = 3 + 4j + 6i + 8ij = 3 + 6i + 4j + 8k$。于是 $N(q_1) = 1 + 4 = 5$，$N(q_2) = 9 + 16 = 25$，而

$$
N(q_1 q_2) = 3^2 + 6^2 + 4^2 + 8^2 = 9 + 36 + 16 + 64 = 125 = 5 \cdot 25,
$$

与范数乘法公式一致。矩阵方面，$L_{q_1}$ 与 $L_{q_2}$ 的行列式分别为 $25$ 与 $625$，所以 $\det L_{q_1} \det L_{q_2} = 15625 = 125^2$，也与 $\det L_{q_1 q_2} = N(q_1 q_2)^2$ 一致。

### 第六步：为什么只有四个维数

四平方和恒等式不是一个孤立的巧合。$n = 1$ 时它平凡；$n = 2$ 时是复数的模相乘，即两平方和恒等式；$n = 4$ 时对应四元数；$n = 8$ 时对应八元数（Cayley 数），也有相应的八平方和恒等式。Hurwitz 定理说：若要求每个 $c_k$ 都是 $a_i,b_j$ 的**双线性型**（关于两组变量分别线性），则
$(\sum a_i^2)(\sum b_j^2)=\sum c_k^2$ 存在当且仅当 $n = 1, 2, 4, 8$，它们分别对应实数、复数、四元数、八元数这四个可除代数。没有双线性要求时，$n=16$ 可取 $c_1=\sqrt{(\sum a_i^2)(\sum b_j^2)}$、其余 $c_k=0$ 这种平凡反例；Hurwitz 定理排除的正是这种退化写法。这里只陈述结论，不展开证明。

$\blacksquare$

## 关键技巧

- **把双线性形式变成矩阵**：四元数乘法对每个因子线性，固定一个因子就得到 $4 \times 4$ 矩阵，代数恒等式随即变成行列式恒等式。
- **正交性给出范数**：$L_q^{\mathsf{T}} L_q = N(q) I_4$ 说明四个列向量两两正交、长度相同，这是乘法表对称性的矩阵表达。
- **行列式的符号靠连通性**：绝对值由 $\det(L_q)^2 = N(q)^4$ 确定，符号在连通的 $S^3$ 上连续且为 $\pm 1$，由 $q = 1$ 定出。
- **次序与符号别弄错**：展开四元数乘法时 $ij = k$ 但 $ji = -k$，次序不同会差一个负号。
- **平方和恒等式是"范数可乘"的坐标写法**：四元数、复数、八元数分别给出四平方、两平方、八平方和恒等式。

## 变式

- **变式 1**：设 $\alpha = a + bi$、$\beta = c + di$，令 $A_q = \begin{pmatrix} \alpha & \beta \\ -\bar\beta & \bar\alpha \end{pmatrix}$。证明 $q \mapsto A_q$ 是四元数代数到 $2 \times 2$ 复矩阵代数的单同态，且 $\det A_q = N(q)$；再用 $\det(A_{q_1} A_{q_2}) = \det A_{q_1} \det A_{q_2}$ 重新证明四平方和恒等式。
- **变式 2**：设 $N(q) \ne 0$，证明 $q^{-1} = \bar q / N(q)$，并验证 $L_q^{-1} = L_q^{\mathsf{T}} / N(q)$；说明单位四元数（$N(q) = 1$）对应的 $L_q$ 是四阶正交矩阵。
- **变式 3**：写出 $n = 2$ 时的两平方和恒等式（Brahmagupta–Fibonacci 恒等式），并用复数的模相乘证明它。
- **变式 4**：查资料了解八元数与八平方和恒等式（Degen 恒等式），并说明为什么八元数乘法不满足结合律却仍能给出平方和恒等式。
