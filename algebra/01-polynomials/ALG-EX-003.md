## 题目

判断下列多项式在 $\mathbb{Q}[x]$ 中是否不可约。若可约，给出因式分解：

1. $f_1(x) = x^5 - 4x + 2$
2. $f_2(x) = x^5 - 4x^2 + 2x - 8$
3. $f_3(x) = x^4 + 1$
4. $f_4(x) = x^5 - x^2 - x + 1$

## 分析

判定有理系数多项式不可约性主要有三种工具，按优先级使用：

1. **Eisenstein 判别法**——若能直接找到素数 $p$ 满足条件，一步判定不可约；
2. **有理根定理 + 次数检查**——若 $\deg \leq 3$，无有理根则不可约（低次特例）；
3. **代换变换**——对不直接满足 Eisenstein 条件的多项式，用 $x \mapsto x + c$ 变换后再试。

本题四个多项式各有代表性：

- $f_1$：可直接用 Eisenstein（取 $p=2$）
- $f_2$：低次检查 → 用有理根定理遍历候选
- $f_3$：经典"无根但可约"反例 → 需特定分解技巧
- $f_4$：有有理根 → 直接因式分解

## 解答

### 第 1 题：$f_1(x) = x^5 - 4x + 2$

**系数分析**：$a_5 = 1$, $a_4 = a_3 = a_2 = 0$, $a_1 = -4$, $a_0 = 2$。

尝试 Eisenstein（$p = 2$）：

- $p = 2 \nmid a_5 = 1$ ✓
- $p = 2 \mid a_4, a_3, a_2$（全是 $0$）✓
- $p = 2 \mid a_1 = -4$ ✓
- $p = 2 \mid a_0 = 2$ ✓
- $p^2 = 4 \nmid a_0 = 2$ ✓

**全部条件满足**。由 Eisenstein 判别法（[[ALG-THM-009]]），

$$
\boxed{f_1(x) \text{ 在 } \mathbb{Q}[x] \text{ 中不可约}}.
$$

**说明**：$x^5 - 4x + 2$ 在 $\mathbb{C}$ 中有 5 个根（代数基本定理），但这些根全部不是有理数，且这个多项式不能分解为两个非常数有理系数多项式之积。

### 第 2 题：$f_2(x) = x^5 - 4x^2 + 2x - 8$

**Eisenstein 检查**：各系数为 $1, 0, 0, -4, 2, -8$。常数项 $-8$ 的素因子为 $2$。

- $p = 2$：$2 \nmid a_5 = 1$ ✓，但 $2^2 = 4 \mid a_0 = -8$ ✗——条件 3 不满足。
- 其他素数 $p$ 不整除 $a_0$，Eisenstein 不可用。

**有理根定理**：首项系数 $1$，常数项 $-8$，有理根候选为 $\pm 1, \pm 2, \pm 4, \pm 8$。

逐一验证：

- $f_2(1) = 1 - 4 + 2 - 8 = -9 \neq 0$
- $f_2(-1) = -1 - 4 - 2 - 8 = -15 \neq 0$
- $f_2(2) = 32 - 16 + 4 - 8 = 12 \neq 0$
- $f_2(-2) = -32 - 16 - 4 - 8 = -60 \neq 0$
- $f_2(4) = 1024 - 64 + 8 - 8 = 960 \neq 0$
- $f_2(-4) = -1024 - 64 - 8 - 8 = -1104 \neq 0$
- $f_2(8) = 32768 - 256 + 16 - 8 = 32520 \neq 0$
- $f_2(-8) = -32768 - 256 - 16 - 8 = -33048 \neq 0$

全部非零，故 $f_2$ **无有理根**。但 $\deg f_2 = 5 \geq 4$，无有理根**不能推出**不可约——必须考虑分解为两个非常数多项式（如三次 × 二次）的可能性。

进一步分析：$f_2$ 模 $3$ 得 $\bar f_2(x) = x^5 - x^2 + 2x + 1 \in \mathbb{F}_3[x]$。验证 $\bar f_2$ 在 $\mathbb{F}_3$ 中无根（代入 $0, 1, 2$ 均非零），且因 $\deg \bar f_2 = 5$ 的不可约性判定需更多工具（Berlekamp 算法），此处从略。

**结论**：$f_2$ 的有理根检查未发现根，但不排除可约为三次 × 二次的可能，留作深入练习。

### 第 3 题：$f_3(x) = x^4 + 1$（经典不可约但有技巧的例题）

**Eisenstein 直接检查**：系数 $1, 0, 0, 0, 1$，常数项 $1$ 无素因子——Eisenstein **不可用**。

**有理根检查**：候选 $\pm 1$，$f(\pm 1) = 2 \neq 0$，无有理根。

**尝试代换**：令 $x = y + 1$，

$$
f_3(y+1) = (y+1)^4 + 1 = y^4 + 4y^3 + 6y^2 + 4y + 2.
$$

用 Eisenstein（$p = 2$）检查 $f_3(y+1)$：

- $2 \nmid 1$ ✓
- $2 \mid 4, 6, 4$ ✓
- $2 \mid 2$ ✓
- $4 \nmid 2$ ✓

全部条件满足！故 $f_3(y+1)$ 在 $\mathbb{Q}[y]$ 中不可约。由于代换 $x \mapsto x+1$ 是 $\mathbb{Q}[x]$ 的自同构（可逆线性变换），

$$
\boxed{f_3(x) = x^4 + 1 \text{ 在 } \mathbb{Q}[x] \text{ 中不可约}}.
$$

**关于 $x^4 + 1$ 在 $\mathbb{R}[x]$ 中的可约性**：$x^4 + 1 = (x^2 + \sqrt{2}x + 1)(x^2 - \sqrt{2}x + 1)$，分解涉及 $\sqrt{2} \notin \mathbb{Q}$。因此在 $\mathbb{Q}[x]$ 中不可约，在 $\mathbb{R}[x]$ 中可约——这体现了底域的重要性。

### 第 4 题：$f_4(x) = x^5 - x^2 - x + 1$

**有理根定理**：首项系数 $1$，常数项 $1$，候选 $\pm 1$。

- $f_4(1) = 1 - 1 - 1 + 1 = 0$ → $x = 1$ 是根！
- $f_4(-1) = -1 - 1 + 1 + 1 = 0$ → $x = -1$ 也是根！

**因式分解**：由因式定理（[[ALG-THM-004]]），$(x-1)(x+1) = x^2 - 1$ 是 $f_4$ 的因式。

做多项式除法：

$$
f_4(x) \div (x^2 - 1) = x^3 + x - 1.
$$

验算：$(x^2 - 1)(x^3 + x - 1) = x^5 + x^3 - x^2 - x^3 - x + 1 = x^5 - x^2 - x + 1$ ✓。

检查 $g(x) = x^3 + x - 1$：候选有理根 $\pm 1$，$g(1) = 1 \neq 0$，$g(-1) = -3 \neq 0$，且 $\deg g = 3$——由三次多项式无有理根则不可约的性质（[[ALG-THM-005]] 与 [[ALG-THM-009]] 结合），$g$ 在 $\mathbb{Q}[x]$ 中不可约。

因此 $f_4$ 在 $\mathbb{Q}[x]$ 中的标准分解为：

$$
\boxed{f_4(x) = (x-1)(x+1)(x^3 + x - 1)}.
$$

## 关键技巧

1. **Eisenstein 优先**：检查常数项的素因子是否满足条件——这是最快的路径。
2. **代换 $x \mapsto x + c$**：当直接 Eisenstein 不适用时，尝试 $c = 1$ 或 $c = -1$ 的平移变换，往往能创造出可用 Eisenstein 的系数模式。
3. **低次不可约判定**：$\deg \leq 3$ 的多项式，无有理根 $\iff$ 不可约。对 $\deg \geq 4$，这个等价性**不成立**。
4. **有理根定理的"负筛选"**：遍历候选有理根全部非零，只能排除一次因子，不能排除二次或更高次的不可约因子。
5. **模 $p$ 约化**（进阶技巧）：将多项式系数模一个素数 $p$ 得到 $\mathbb{F}_p[x]$ 中的多项式，若它在 $\mathbb{F}_p[x]$ 中不可约，则在 $\mathbb{Q}[x]$ 中也不可约。
