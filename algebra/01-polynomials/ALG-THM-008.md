## 条件

设 $f(x) \in \mathbb{R}[x]$ 是实系数多项式，$\deg f = n \geq 1$。

## 结论

> **共轭根成对定理**：若非实数 $z = a + b\mathrm{i}$（$b \neq 0$）是 $f$ 的根，则其共轭 $\bar z = a - b\mathrm{i}$ 也是 $f$ 的根，且**重数相同**。

### 实系数标准分解形式

$f(x)$ 在 $\mathbb{R}[x]$ 中可唯一分解为如下形式：

$$
f(x) = c \cdot (x - r_1)^{e_1} \cdots (x - r_k)^{e_k} \cdot (x^2 + p_1 x + q_1)^{f_1} \cdots (x^2 + p_m x + q_m)^{f_m},
$$

其中：

- $c \in \mathbb{R}^\times$ 是首项系数；
- $r_i \in \mathbb{R}$ 是实根，$e_i$ 为对应重数；
- 每个二次式 $x^2 + p_j x + q_j$ 的判别式 $\Delta_j = p_j^2 - 4q_j < 0$（即不可约），对应一对共轭复根；
- $k + 2m = n$（次数守恒）。

## 几何/直觉理解

> 实系数多项式像一面镜子——复根必须成对出现在镜子的两侧。

**为什么成立**：取共轭是 $\mathbb{R}$ 上的恒等映射（$\bar r = r$ 对 $r \in \mathbb{R}$），且对多项式求共轭就是**系数取共轭**。因为系数全是实数，故 $\overline{f(z)} = f(\bar z)$。若 $f(z) = 0$，两边取共轭得 $f(\bar z) = \overline{f(z)} = 0$——$\bar z$ 也必然是根。

**为什么重数相同**：若 $(x - z)^k \mid f(x)$ 且 $z$ 非实数，则 $(x - \bar z)^k \mid f(x)$，否则 $f$ 的系数不可能全是实数。严格证明可对唯一分解（[[ALG-THM-002]]）取共轭得到。

**标准分解的意义**：$\mathbb{R}[x]$ 的不可约多项式只有两类——一次式（对应实根）和判别式 $<0$ 的二次式（对应共轭复根对）。这是代数基本定理（[[ALG-THM-007]]）在实数域的投影。

## 证明

**共轭根成对**：设 $z \in \mathbb{C}$ 是 $f$ 的根，即 $f(z) = 0$。写出 $f(x) = a_n x^n + \cdots + a_0$，$a_i \in \mathbb{R}$。取共轭：

$$
0 = \overline{0} = \overline{f(z)} = \overline{a_n z^n + \cdots + a_0} = a_n \bar z^{\,n} + \cdots + a_0 = f(\bar z).
$$

故 $\bar z$ 也是根。

**重数相同**：设 $z$ 的重数为 $k$，即 $(x - z)^k \mid f(x)$ 但 $(x - z)^{k+1} \nmid f(x)$。由于 $f$ 的系数为实数，将 $f$ 的唯一分解（[[ALG-THM-002]]）$(x - z)^k$ 部分取共轭得 $(x - \bar z)^k$，故 $\bar z$ 的重数 $\geq k$。同理，由对称性得 $z$ 的重数 $\geq \bar z$ 的重数，故相等。$\blacksquare$

**标准分解**：由共轭根成对及代数基本定理（[[ALG-THM-007]]）知：$f$ 在 $\mathbb{C}[x]$ 中可完全分解为一次因式 $(x - r)$。每对共轭虚根 $z, \bar z$ 相乘即得不可约二次式：

$$
(x - z)(x - \bar z) = x^2 - (z + \bar z) x + z\bar z = x^2 - 2a\, x + (a^2 + b^2),
$$

其实系数判别式 $\Delta = (2a)^2 - 4(a^2 + b^2) = -4b^2 < 0$。将所有实根的一次因式与这些二次式乘起来即得 $\mathbb{R}[x]$ 中的标准分解。$\blacksquare$

## 常见错误

- ✗ 认为"实系数多项式一定有实根"。  
  反例：$x^2+1$ 无实根。共轭根成对定理保证的是"若有虚根则成对"，而不是"一定有实根"——3 次实系数多项式才有（至少）一个实根（奇数次 + 实系数连续性）。
- ✗ 忽略重数相同这一条件。  
  反例场景：$(x - \mathrm{i})^2 (x + \mathrm{i})$ 的系数不是实数（$\mathrm{i}$ 是 2 重根而 $-\mathrm{i}$ 是 1 重根时，乘积展开系数含有虚部）。检查：$(x-\mathrm{i})^2(x+\mathrm{i}) = (x^2 - 2\mathrm{i}x -1)(x+\mathrm{i})$ 展开系数有虚部。
- ✗ 把"判别式 $<0$ 的二次式"与"$\mathbb{R}[x]$ 中任意二次式"混淆。  
  判别式 $\geq 0$ 的二次式在 $\mathbb{R}[x]$ 中可约（如 $x^2 - 1 = (x-1)(x+1)$），不属于标准分解中的二次因子——它是两个一次因式的乘积。

## 推论

1. **$\mathbb{R}[x]$ 不可约多项式分类**：只有一次式和判别式 $<0$ 的二次式。
2. **奇次实多项式必有实根**：次数为奇数的实系数多项式至少有一个实根（在标准分解中，奇数次的分解中不可能只有二次因子）。
3. **实对称矩阵的特征值全是实数**（谱定理的结论之一，参见 ALG-THM-044，待建）。

## 跨专业应用

- **物理**：线性微分方程 $a_n y^{(n)} + \cdots + a_0 y = 0$ 的特征方程是实系数多项式。共轭复根 $a \pm b\mathrm{i}$ 对应解中的振荡模态 $e^{at}(C_1\cos bt + C_2\sin bt)$——成对出现保证了实数解
- **信号处理**：实系数滤波器的传递函数的零点和极点必须共轭成对，否则冲击响应会含有虚部（物理不可实现）
